# 三仓库开发与发布

2026-11-07 将原 `yuwatang-reservation` 中的最新业务代码同步到三个独立 Git 仓库。以下目录是后续开发入口；各仓库的 Git 历史和远端保留，旧目录及覆盖前的文件留作本地备份。

| 本地目录 | 职责 | 验证与产物 |
| --- | --- | --- |
| `D:/github_code/裕和堂相关项目/yuhetang-miniprogram` | 微信原生小程序，开发者工具直接打开仓库根目录 | `npm run check:mini`；由微信开发者工具编译与上传 |
| `D:/github_code/裕和堂相关项目/yuhetang-miniprogram-admin` | React 管理后台和客户 H5 预览 | `npm ci`、`npm run build`；`dist/` |
| `D:/github_code/裕和堂相关项目/yuhetang-miniprogram-backend` | Java API、数据库迁移、部署和验收工具 | `mvn -B -ntp -Papi-release verify`；`target-api/reservation-api-1.0.0.jar` |

三个仓库放在同一父目录。Java 的 `frontend.dist`、`frontend.media` 分别默认读取相邻管理后台仓库的构建产物和公开素材；API JAR 只包含后端与公开素材，不包含管理后台 HTML/JS。`release` profile 继续用于本地合并预览。数据库默认路径是后端仓库自身的 `data/`，不会回指旧工程的业务数据库。

## 本地联调

后端执行 `mvn spring-boot:run`，API 默认端口 8790；管理后台执行 `npm run dev`，默认端口 5181，以 `API_PROXY_TARGET` 调整开发代理。也可以在后端执行 `tools/start-local.ps1 -Build` 构建相邻后台并启动本地合并预览。

小程序 `config.js` 默认连接 `https://booking.yuhetangtcm.com`，`useLocalBackend=false`、`developmentLogin=false`。显式开启本地选项只用于开发者工具联调；发布前恢复默认值。

## 分开部署与后续更新

后台静态文件发布到 `mp-admin.yuhetangtcm.com`，Java 服务单独升级；同域 `/api/` 代理到后端。仅微信客服回调使用 `booking.hetuonian.cn`，不变更现有后台和业务 API 域名。详细首次安装、备份、回滚验证和升级步骤见 [1Panel 部署](../deploy/1panel/README.md)。

在后端仓库准备完整发布包前依次执行：

```powershell
Push-Location ../yuhetang-miniprogram-admin
npm ci
npm run build
Pop-Location
New-Item -ItemType Directory -Force logs | Out-Null
Push-Location ../yuhetang-miniprogram
npm run check:mini | Tee-Object ../yuhetang-miniprogram-backend/logs/1panel-mini-check-20261107.log
Pop-Location
mvn -B -ntp -Papi-release verify
python tools/verify-tencent-isolation.py
python tools/verify-1panel-split.py
python tools/package-1panel.py --release-date 20261107
```

使用本次实际发布日期替换日志和打包参数中的日期。完整打包还需按脚本要求在忽略的 `backups/tencent-java17-runtime/` 准备匹配 SHA256 的 Java 17 运行包。脚本校验测试、独立代理验证及产物哈希；不会覆盖已有同名发布包。发布产物写入忽略的 `releases/`。源目录中的历史发布包、验证缓存和运行时没有随源码自动搬入，也不会作为本次验证结果。

只更新页面时，构建并部署后台 `dist/`；只更新接口时，备份本项目数据库、上传文件和环境配置，再替换独立 API JAR。首次安装脚本不作为日常更新脚本。模板映射、门店项目和已支持的内容通过后台/API 更新；客户端页面、权限或逻辑变化仍需小程序重新发布。

Compose 模板保留作可选方案，不用于当前 1Panel 首次安装。它从三个仓库的父目录构建，`Dockerfile.dockerignore` 将构建上下文限制为前后端源码及公开素材；默认不发送本地数据、密钥或生成产物。

## 数据与验收范围

`.env.local`、数据库、上传数据、证书私钥、日志、备份和发布压缩包不提交。需要迁移业务资料时另行备份和导入。本次迁移不调整云端服务，也不替代真实微信客服收发、订阅消息送达、真机审核和云端容量验收；5 万同时在线仍需在目标环境压测。

其余部署和验收文档包含此前合并工程的历史命令，涉及 `backend/`、根目录 `miniprogram/` 或根目录 `dist/` 时，以本文的独立仓库对应路径为准。
