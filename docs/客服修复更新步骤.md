## 2. 替换 Java 容器

先确认目前 Java 容器的实际名称：

```bash
docker ps --format '{{.Names}}  {{.Image}}  {{.Status}}'
```

你最近给出的运行中 Java 容器名称为 yuhetang-java-api-failed-20261107-182144。名称带 failed 但当时状态为 healthy；不要因为名称删除它。如果已变更，请将下面 YHT_OLD_JAVA 改成当前 Java 容器名。不要填 OpenResty 或 MySQL 容器名。以下代码块使用 `bash -e`，任一步失败会停止，不继续覆盖或切换。

```bash
bash -e <<'YHT_UPDATE_JAVA'
cd /root/yuhetang-upload/yuhetang-java-docker-20261107-195806
YHT_OLD_JAVA=yuhetang-java-api-failed-20261107-182144
docker inspect --format '{{.Name}}  {{.Config.Image}}  {{.State.Status}}' "$YHT_OLD_JAVA"
test "$(docker inspect --format '{{.State.Running}}' "$YHT_OLD_JAVA")" = true
test -f /etc/yuwatang-reservation.docker.env
test ! -e /var/backups/yuhetang-chat-20261107-195806
for YHT_NAME in yuhetang-java-api yuhetang-java-api-before-20261107-195806; do
  if docker container inspect "$YHT_NAME" >/dev/null 2>&1; then
    printf 'STOP: container %s already exists; inspect it before continuing.\n' "$YHT_NAME" >&2
    exit 1
  fi
done
install -d -o root -g root -m 0700 /var/backups/yuhetang-chat-20261107-195806
install -o root -g root -m 0600 /etc/yuwatang-reservation.docker.env /var/backups/yuhetang-chat-20261107-195806/
# 保存旧容器与旧环境文件；切换失败时只恢复这个 Java 容器。
docker stop --time 50 "$YHT_OLD_JAVA"
if ! docker rename "$YHT_OLD_JAVA" yuhetang-java-api-before-20261107-195806; then
  docker start "$YHT_OLD_JAVA"
  exit 1
fi
if ! bash run.sh yuhetang-java-api:20261107-195806; then
  if [ "$(docker inspect --format '{{.State.Running}}' yuhetang-java-api 2>/dev/null || true)" = true ]; then
    printf 'New Java container exists; check its health before restoring the old container.\n' >&2
  else
    docker start yuhetang-java-api-before-20261107-195806
  fi
  exit 1
fi
YHT_UPDATE_JAVA
```

新容器启动后检查：


## 4. 真实客服验收

1. 客户重新从小程序进入客服，发送一条新的测试消息。
2. 管理后台点击“客户沟通”。总部默认全部门店、全部状态；确认左侧有会话、右侧有消息内容。
3. 回复一条消息，确认客户端实际收到。
