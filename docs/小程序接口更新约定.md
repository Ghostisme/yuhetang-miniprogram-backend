# 小程序接口更新约定

2026-11-05：日常经营内容和已有功能的规则优先通过后台/API 更新，减少小程序代码发布。当前原生小程序目录为 `miniprogram/`，接口域名固定为 `https://booking.yuhetangtcm.com`。迁服务器时保持域名和 API 合约稳定，调整 DNS/反向代理即可，不把服务器 IP 写入客户端。

管理后台使用独立入口 `https://mp-admin.yuhetangtcm.com/admin`，由 1Panel OpenResty 提供静态前端，`/api/` 和 `/uploads/` 转发到独立 Java 服务；小程序的 `apiBase`、合法域名和客服回调继续使用 booking。前端和 Java 分别更新，不需要因管理后台改版发布小程序，部署见 [1Panel 操作说明](../deploy/1panel/README.md)。

## 已通过接口提供的内容

| 内容 | 修改入口或后端配置 | 小程序读取方式 |
| --- | --- | --- |
| 品牌名、介绍、封面、图文、预置配色、已有首页版块的排序与显隐、产品内容 | 总部「品牌与内容」保存并发布，按 RBAC 授权 | `/api/site` |
| 门店地址、电话、封面、相册、营业时间、门店展示信息 | 「门店与时段」及总部对应权限 | `/api/site` |
| 各店独立品项、介绍、启停、图片等现有品项字段 | 门店「品牌与内容」的本店品项，受门店范围与 RBAC 限制 | `/api/stores/{id}/services` |
| 本店调理师及可服务品项 | 「调理师管理」 | `/api/stores/{id}/therapists` |
| 可预约日期、时段、人数上限、停约及实际剩余名额 | 「门店与时段」 | `/api/stores/{id}/slots`；提交仍由后端再次校验 |
| 我的预约与处理状态 | 门店处理预约 | `/api/me/appointments` |
| 客户订阅模板 ID | 后端 `CUSTOMER_TEMPLATE_ID` / `CUSTOMER_REMINDER_TEMPLATE_ID`，修改后重启本项目应用 | `/api/runtime`；客户端不内置模板 ID |
| 订阅字段映射与通知渠道开关 | 总部「扩展与配置」和「消息中心」对应设置 | 服务端生成消息并发送 |
| 门店、项目等图片 | 后台现有图片上传与素材功能 | 当前读取接口返回的 `/media/`、`/uploads/` 地址；OSS 直传及外部 URL 的统一支持仍需另外接入，不能只添加合法域名就替代上传实现 |

模板 ID 变更后，客户需要主动订阅新的模板；旧模板授权不会变成新模板授权。接口下发配置不取消微信对一次性订阅次数的限制。

## 本次客户端补齐

- 默认包括微信开发者工具在内的所有环境都连接 `https://booking.yuhetangtcm.com`。只有显式设置 `miniprogram/config.js` 的 `useLocalBackend:true`，并且是 `develop` + 微信开发者工具 `devtools` 时，才连接 `http://127.0.0.1:8790`；真机预览、体验版、正式版和环境识别失败仍连接正式域名。
- 模拟客户登录仍关闭。需要真机访问本地服务时，应另行配置可达的开发地址和微信开发环境，不把真机的 `127.0.0.1` 当成电脑地址。
- `/api/site` 和 `/api/runtime` 各缓存 60 秒，同一个运行实例的并发读取共用请求。缓存过期后，在页面下一次读取时更新，不额外高频轮询全站配置。
- 首页下拉刷新绕过客户端内容缓存；服务端公开内容缓存最多约 3 秒。切换到首页、养护、门店时按缓存期限读取已发布内容。停留页面不会因为后台发布而自动重绘。
- 我的预约轮询共用订阅配置缓存；模板配置更新后会在后续读取时获得新 ID。新开预约页同样读取运行配置。
- 首页分享文案使用后台下发的品牌名和简介。

## 仍需代码发布的范围

新增原生页面、组件交互、客户端计算逻辑、原生能力或权限、隐私声明相关能力，以及无法由现有组件表达的新版布局，需要修改小程序代码，并按微信发布流程处理。现有页面中的固定按钮文案、静态页签名称也不是全部都已做成后台配置。后端业务修复可单独部署；如果 API 字段发生不兼容变化，应保留旧版兼容期并联合验收客户端。

接口用于下发数据与现有功能配置，不下载和执行远程 JavaScript，也不把新增原生功能藏在配置后绕过审核。小程序第一次切换到本项目、接入现有原生客服入口和这次客户端补齐，仍需统一完成一次开发者工具编译、真机验收与提交；之后日常品牌/门店/品项/预约规则更新由后台完成。

本次 `npm run check:mini` 覆盖正式 API 选择、配置缓存合并/过期/失败重试、运行中模板 ID 更新、首页强制刷新及已有预约、订阅、客服控制器检查。该检查不能替代微信开发者工具编译和实际消息投递。

官方依据：[账号环境信息](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/account-info/wx.getAccountInfoSync.html)、[网络与合法域名](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[订阅消息](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/subscribe-message.html)。
